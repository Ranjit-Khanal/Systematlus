# E2E Request

## Concept

Production requests cross every layer. This experiment runs **one** `GET /api/users` and measures each hop:

```
DNS (localhost)
  → TCP connect (127.0.0.1:port)
    → HTTP GET
      → handler
        → SQLite SELECT
          → JSON response
```

## Real in this lab

| Step | Measurement |
|---|---|
| DNS | `net.Resolver.LookupIP("localhost")` |
| TCP | `net.Dial` timing to server port |
| HTTP | Client `Get` + status/bytes |
| DB | Handler `db.Query` duration + rows |
| Sockets | `ss` samples during phases |

Stack path diagram is **SIMULATION**.

## Experiment

**System Map → SEND REQUEST — E2E** or **E2E REQUEST** nav.

Optional: `SYSLAB_E2E_DOMAIN=localhost` on the experiment process.

## Why it matters

“Slow API” tickets need layer isolation. E2E shows whether time is in DNS, connect, handler, or query — with REAL timings, not guessed percentages.
