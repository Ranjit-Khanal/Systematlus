THE MACHINE
— an operating system you can fly through

A small computer, actually executing instructions — a real x86-64 subset interpreter, real 4-level page tables, a real scheduler, a real TCP stack — rendered as a physical machine across four floors: user space, the syscall boundary, the kernel, and hardware. Nothing here is a pre-baked animation; every particle you see is a consequence of the simulation underneath.
